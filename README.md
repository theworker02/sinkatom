# sinkatom

Sink URLs and atom query parts with stable normalization.

**Site:** https://theworker02.github.io/sinkatom/

## Install / run

```bash
git clone https://github.com/theworker02/sinkatom.git
cd sinkatom
node src/cli.js
node --test
```
